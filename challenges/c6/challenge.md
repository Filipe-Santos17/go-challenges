# Minimalist Task Manager

Implement a small task manager that runs in the terminal. The user can:

- Add a task (free text)
- List all tasks with index
- Mark a task as completed (by index)
- Remove a task (by index)
- Everything should run in memory (no database). Each task has text and status (incomplete/complete).

Tip: Use slices to store tasks dynamically. A Task struct with appropriate fields. Receiver methods help organize operations.
