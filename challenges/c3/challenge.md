# Word Frequency Analysis

A data analyst needs to know which words appear most often in a long text (an article, for example). Given a string containing letters, punctuation and spaces, produce a map that associates each word (lowercase, without punctuation) with its count. Then, list the 5 most frequent words.

Hint: Maps are ideal for counting. Use the `strings` package for normalization. How do you extract the 5 highest counts from a map?
