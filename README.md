# go-challenges

![Gopher](https://yourbasic.org/golang/square-gopher.png)

A collection of **Golang challenges created with AI** to practice and improve my Go skills through hands-on exercises.

## 🎯 Purpose

This repository is focused on learning Go through practical challenges, covering concepts from the basics to more advanced topics.

## 📚 Topics

* Variables and data types
* Arrays and slices
* Maps
* Structs
* Functions
* Pointers
* Interfaces
* Error handling
* Goroutines
* Channels
* Concurrency
* Packages
* Testing
* File handling
* APIs
* And more

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Filipe-Santos17/go-challenges
cd go-challenges
```

Run a challenge:

```bash
go run challenges/c1/c1.go
```

## 📁 Structure

Each challenge is organized independently according to the concept being practiced.

```text
├── challenges

│   │   └── challenge.md
│   └── c2

```
